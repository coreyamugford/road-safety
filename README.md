# Road Safety

An original 3D driving game for kids that teaches the rules of the road. Pick and paint a car, choose your passengers, buckle everyone up, and drive them around town to the places they want to go.

Open `index.html` in any browser to play (works on computers, phones and tablets, including Fire tablets). It needs an internet connection the first time it loads, to fetch the 3D engine.

## What's in it

- **Garage:** 8 car shapes (2-Door, 4-Door, Mini Car, Bug, Minivan, Sedan, Pickup, SUV), colours, patterns, window tint, convertible roof, wheels and your own licence plate.
- **Passengers:** pick who rides along, or shuffle. Some need help: Baby rides in a car seat, Sam uses a wheelchair, Uncle Ray uses a white cane, Grandpa uses a walker.
- **A living town:** stores, homes, a school, park, hospital, police and fire stations, people walking, other cars, police patrols and a school bus.
- **Rules of the road:** traffic lights, STOP signs, crosswalks, speed limits, turn signals, headlights at night, seatbelts and school bus stops. Police only give tickets if they see you, and red light cameras send a ticket with a photo.
- **Airbags:** a hard crash sets off a big friendly airbag and a short safety lesson.
- **Two views:** bird's-eye and behind-the-car (press C).

## Controls

| Key | Action |
| --- | --- |
| Arrow keys / WASD | Drive and steer |
| Space | Brake |
| Q / E | Left / right turn signal |
| L | Headlights |
| H | Horn |
| B | Buckle up a passenger (stop first) |
| C | Switch view |
| P | Pause |
| M | Sound on or off |

On a tablet or phone, use the big buttons on the screen.

Built with [three.js](https://threejs.org/) (MIT licence).
